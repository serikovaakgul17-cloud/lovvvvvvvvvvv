# Ваши фотографии

Положи сюда реальные фотографии вас двоих и назови их так:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`
- `photo-4.jpg`

Можно использовать `.jpg`, `.png` или `.webp`, но если меняешь расширение, также измени путь в `story.html` в атрибуте `data-photo`. Пока фотографий нет, сайт покажет аккуратные заглушки — случайные снимки не подставляются.
