# Love Site — для Сары ❤️

Нежный многостраничный сайт-подарок. В проекте используются HTML, CSS и обычный JavaScript без сервера, регистрации, базы данных или платных API.

## Запуск
1. Распакуй папку `love-site`.
2. Открой `index.html` в браузере. Для удобной разработки можно открыть папку в VS Code и запустить через расширение Live Server.
3. Переходи между страницами через меню. Вкладка «Напоследок» — последняя страница: ответ «Нет, обратно» возвращает на главную, а «Да» запускает фото-салют и показывает кнопку перехода на TikTok.

## Страницы
- `index.html` — приглашение на свидание 24 октября 2026 года.
- `story.html` — история отношений и фотоальбом.
- `nicknames.html` — карточки прозвищ на казахском и русском.
- `memories.html` — динамический счётчик дней и праздничных дат.
- `love.html` — любовное письмо.
- `final.html` — последняя страница-сюрприз с переходом на TikTok.

## Добавление фотографий
Смотри `assets/images/README.md`. Добавь свои снимки под именами `photo-1.jpg` ... `photo-4.jpg`. Если используешь другие имена или расширения, поменяй значения `data-photo` в `story.html`.

## Персональные заметки
Текстовые поля на странице истории сохраняются в `localStorage` текущего браузера. Даты рождения на странице счётчика тоже сохраняются локально. Данные не отправляются на сервер.

## Важно про счётчик
- Начало отношений задано один раз в `js/counter.js`: `START = {year: 2024, month: 10, day: 24}`.
- Число дней — количество прошедших календарных суток между датой начала и текущей датой.
- Счётчик праздников считает календарные даты с 24.10.2024 включительно по сегодняшнюю дату включительно. Для Наурыза отдельно считаются ежегодные начала праздника 21 марта и все три даты 21–23 марта.
- Дни рождения учитываются только после ввода дат.

## Настройка
Цвета и адаптивная вёрстка находятся в `css/style.css`. Основная логика приглашения — `js/main.js`, эффекты — `js/animations.js`, галерея — `js/gallery.js`, прозвища — `js/nicknames.js`, счётчики — `js/counter.js`.

Сайт учитывает `prefers-reduced-motion` и не запускает музыку автоматически.
